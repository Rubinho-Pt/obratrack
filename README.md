## About

ObraTrack helps construction professionals organize activities, deadlines, and priorities through a clean and focused dashboard. It was built to make day-to-day project tracking simpler without requiring an account, installation, or complex setup.

> All data stays on the user's device and the application works directly in the browser.

## Highlights

| Project planning | Reliable experience |
| --- | --- |
| Create and organize tasks | Safe browser storage |
| Assign tasks to projects | Corrupted-data recovery |
| Set deadlines and priorities | Validated tasks and priorities |
| Complete or reopen tasks | Protected double-click handling |
| Filter by task status | Clear loading and error states |

## Multilingual by design

Switch languages instantly without reloading the page. ObraTrack remembers the selected language for the next visit.

## Built for every screen

The interface adapts to desktop, tablet, and mobile devices while preserving a clear visual hierarchy, accessible focus states, and touch-friendly controls.

## Technology

- **HTML5** for semantic and accessible structure
- **CSS3** for the responsive design system and interface states
- **Vanilla JavaScript** for application logic and localization
- **Web Storage API** for local task persistence
- **GitHub Pages** for deployment

No frameworks, dependencies, or build process are required.

## Run locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Rubinho-Pt/obratrack.git
   ```

2. Open the project folder.
3. Launch `index.html` in a modern browser.
